## 导语

视频文件压缩按「目标体积」工作：你填平台写的那个数字，程序反推码率、两遍编码，压到为止；超差自动修正，压不到会直说。微信直发视频的门槛是 25MB，这也是默认值。

## 开始之前

- 已打开视频文件压缩（窗口标题：视频文件压缩 · 创炫互动）
- 支持 mp4 / mov / mkv / avi / flv / wmv / webm / m4v / ts / 3gp / mpg，输出统一 mp4
- 不用另装 ffmpeg：安装包和免安装版里都带了
- 磁盘留出空间：每条结果都是新文件，体积约等于目标体积 × 条数

## 操作步骤

### 1. 把视频加进来

把视频或整个文件夹拖到窗口顶部的虚线框里；不想拖就点「选择视频」或「选择文件夹」（选文件夹会连子文件夹一起找）。加进来马上看到清单：文件名、时长、原体积、原片分辨率，状态「待压缩」——还没压就能确认选对没有。

### 2. 填目标体积

在「目标体积」填平台给的数字，单位 MB，可填 1–102400（默认 25）。不确定就选常用场景预设：微信直接发视频 25MB、邮件附件 50MB、平台投稿 100MB、高清留档 500MB。别猜，照抄对方页面写的数字，选完仍可手改。

### 3. 一般不用动尺寸设置

「保持原尺寸」默认勾选：只压体积，宽高一点不动；体积够用就不会降分辨率，只压码率。只有平台明确要求分辨率时才取消勾选填宽高（见进阶教程）。

### 4. 点「开始压缩」

进度条显示百分比、已用时间和预计剩余。压缩速度约 0.3–0.4 倍实时：1 分钟片子十来秒，10 分钟片子 25–35 分钟，长片子让它跑着即可。中途可取消，真的会掐掉正在跑的编码，不留半截文件。

### 5. 看结果并取片

跑完状态栏显示「达标 N / N」并自动打开结果文件夹；结果在每段原片旁的 out 子目录，同名自动加 (1)(2) 序号绝不覆盖。「说明」列逐条写明码率从多少降到多少、分辨率有没有降、音频是复制还是重编；双击任意一行看完整披露。

## 常见问题

### Q: 显示「未达标」怎么办？

A: 说明降到画质地板（短边 480p、200kbps）仍超目标。三种处理：片子太长就先剪短或调高目标；目标填得太狠就调到合理值；源片本身是低码率就接受原样或重新导出。程序不会交一段满屏色块却标「达标」的视频。

### Q: 画质损失写在哪儿？

A: 每条结果的「说明」列直接写，例如「有损：分辨率 1920×1080 → 1280×720；码率 7269 → 512 kbps；音频 128 → 96 kbps」，双击该行还能看完整披露。

### Q: 原片会被修改吗？

A: 不会。原片一个字节不改，报告里带前后哈希比对；结果全部写在旁边的 out 文件夹。

### Q: 会上传我的视频吗？

A: 不会。全程本地处理，状态栏常驻显示「本次 0 次联网 / 未发起任何连接」，不上传、不注册、不收集。

## 进阶技巧

- 100MB 以内的目标基本不会触发降分辨率，1080p 长片尺寸原样保留。
- 4K 片子体积够用时保持 3840×2160 只降码率（实测 39.1MB → 23.1MB 保持原分辨率）。
- 压缩中关窗口会先问你，已完成的保留在 out，未完成的标「已取消」。
